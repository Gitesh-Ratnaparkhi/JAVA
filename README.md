# ☕ Java Learning & Practice Repository

A personal repository documenting my journey of learning **Java**. It contains source code, coding exercises, fundamental concepts, Object-Oriented Programming (OOP) implementations, and mini-programs built while exploring the language.

---

## 📌 Repository Contents

* 🧱 **Java Fundamentals:** Variables, data types, operators, conditional statements (`if-else`, `switch`), and loops (`for`, `while`).
* 🧩 **Object-Oriented Programming (OOP):** Classes, objects, inheritance, polymorphism, encapsulation, and abstraction.
* 📦 **Data Structures & Collections:** Arrays, `ArrayList`, `HashMap`, and standard algorithms.
* 🛠️ **Utility Programs & Exercises:** Practice problem solutions, pattern printing, and simple console utilities.

---

## 🛠️ Tech Stack

* **Language:** Java (JDK 8+)
* **Tools:** VS Code / IntelliJ IDEA / Eclipse
